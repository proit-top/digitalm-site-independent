# Сайт digitalm.agency

Статический сайт: одна страница, без базы данных и без сборки. Содержимое этой папки кладётся
в корень домена как есть. Подойдёт любой веб-сервер (nginx, Apache) или статический хостинг.
Внешних подключений нет: шрифты, картинки и скрипты лежат в самой папке.

## Что в папке
- `index.html` — сайт целиком (стили, разметка, скрипты внутри)
- `mobile.css` — раскладка для телефонов и вертикальных планшетов
- `settings.js` — настройки: адрес для заявок и контакты (см. ниже)
- `fonts/` — шрифты (IBM Plex Sans, IBM Plex Mono, Viaoda Libre — свободная лицензия OFL)
- `foto/` — фотографии команды и кейсов
- `politika.html` — страница политики обработки персональных данных
- `favicon.svg`, `apple-touch-icon.png` — иконки сайта
- `og.png` — превью при отправке ссылки в мессенджерах
- `robots.txt` — индексация разрешена

## Что настроить — всё в `settings.js`
**1. Адрес для заявок — `FORM_ENDPOINT`.** На сайте две формы: «Связаться» и «Кейсы».
Обе отправляют `POST` (`multipart/form-data`) на этот адрес. Если оставить его пустым, заявка
никуда не уходит, хотя посетитель видит «спасибо». Куда пересылать дальше (почта, CRM, телеграм) —
на ваше усмотрение.

| поле | что внутри |
|---|---|
| `source` | `связаться` или `кейсы` — из какой формы пришла заявка |
| `name` | имя |
| `company` | компания |
| `email`, `phone` | почта и телефон (форма «Связаться») |
| `task` | описание задачи (форма «Связаться») |
| `file` | прикреплённый файл, может быть пустым (форма «Связаться») |
| `contact` | почта или телефон одной строкой (форма «Кейсы») |
| `agree` | согласие на обработку данных (`on`) |

Ответ `2xx` — заявка принята, посетитель видит «спасибо». Любой другой ответ — форма показывает ошибку.
Размер прикреплённого файла сайт не ограничивает, лимит ставится на сервере.

**Заявки в Битрикс24.** Формат формы — свой, не битриксовый, поэтому нужен небольшой обработчик
на вашем сервере: принимает POST с сайта и создаёт лид методом `crm.lead.add` (например, `name` → `NAME`,
`company` → `COMPANY_TITLE`, `email`/`phone`/`contact` → `EMAIL`/`PHONE`, `task` → `COMMENTS`,
`source` — в `TITLE` или `SOURCE_DESCRIPTION`). Файл из формы «Связаться» передаётся отдельно —
на ваше усмотрение (диск Битрикса или ссылка в комментарии).
⚠ Адрес входящего вебхука Битрикса содержит секретный ключ — **не вписывайте его в `settings.js`**:
этот файл открыт любому посетителю. В `FORM_ENDPOINT` — только адрес вашего обработчика, вебхук — внутри него.

**2. Контакты — `CONTACTS`.** Телефон, телеграм, вотсап, макс, почта. Вписать значение — контакт
появляется на сайте. Пустые кавычки — контакт скрыт. Сейчас включена только почта.

После правки `settings.js` браузеры могут какое-то время показывать старую версию из кэша.
Чтобы этого не было, поменяйте в `index.html` хвост `settings.js?v=1210` на новый (например, дату правки)
или отдавайте `settings.js` с `Cache-Control: no-cache`.

## До запуска
- **HTTPS обязателен:** формы передают персональные данные.
- **Политика:** в `politika.html` сейчас заглушка. Текст даёт юрист Digital M.
- **Домен:** превью ссылок настроено на `https://digitalm.agency/` — сайт должен стоять в корне этого домена.
- **Аналитика:** на сайте её нет. Если нужна Яндекс Метрика, её код вставляется перед `</head>` в `index.html`.

## Проверка после выкладки
1. Открыть сайт с компьютера и с телефона: всё листается, меню открывается.
2. Отправить тестовую заявку из обеих форм и убедиться, что она дошла.
3. Отправить ссылку на сайт в телеграм: должно появиться превью с картинкой.
