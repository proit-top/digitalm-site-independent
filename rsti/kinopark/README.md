# Презентация РСТИ · ЖК «Кинопарк»

Статичная страница: `index.html` + папки `fonts/`, `rsti/` (картинки и ролики), `vendor/` (ECharts). Сборки и серверной части нет.

**Где разместить:** `digitalm.agency/rsti/kinopark/` — содержимое репозитория целиком в эту папку. Все пути относительные, работает из любой папки.

- В `index.html` стоит `<meta name="robots" content="noindex, nofollow">` — внутри стратегия клиента, в поиск страница попадать не должна. Не убирать.
- Листание — колесо, стрелки, пробел; адрес `#N` открывает N-й слайд.
- Обновления презы Антон присылает сюда же новыми коммитами: после `git pull` просто перезалить папку.
